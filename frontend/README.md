# JeevanSetu Frontend

A responsive React/Vite implementation of the JeevanSetu AI-assisted healthcare referral and coordination homepage.

## Requirements
- Node.js 18+ recommended
- npm

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown by Vite, normally `http://localhost:5173`.

## Build for production

```bash
npm run build
npm run preview
```

## Included
- Responsive navigation
- JeevanSetu branding
- Hero section
- Refer a Patient and Manage Facilities actions
- Healthcare referral map illustration built with CSS/SVG
- Benefits strip
- How JeevanSetu Works workflow
- Facility onboarding section
- Why JeevanSetu section
- Contact section
- Responsive mobile navigation
- Language dropdown UI

## Backend integration points
The buttons are currently frontend placeholders. Connect them to your backend for:
- Hospital authentication
- Referral creation
- Facility registration and updates
- Facility/resource availability
- AI/context-aware matching
- Real-time notifications
- Referral status tracking
- Escalation workflows
